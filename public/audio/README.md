# Ambient Music

Place the licensed, royalty-free violin track here as `mary-theme.mp3`
(referenced by `components/AmbientMusicControl.tsx`).

- Must be a properly licensed, royalty-free track (e.g. purchased from Envato)
- Do not add a copyrighted track from an unverified source

Until a licensed file is placed here, the play/pause control remains visible
and keyboard-accessible but will show a "coming soon" state if pressed.
